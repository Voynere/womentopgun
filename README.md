# Women Top Gun

Live product for the **Women in Biz** club: a public member rating, personal cabinets, admin tools, and Telegram bots.

**Live:** [womentopgun.ru](https://womentopgun.ru)

## What it is

A production Symfony application that runs the club’s monthly rating and day-to-day operations:

- Public leaderboard with live updates, podium, and month/category filters
- Member directory, org roster, and participant profile pages
- Personal cabinet (profile, calendar, notifications, analytics)
- Web admin (participants, awards, events, exports)
- Telegram user + admin bots (events, signup, notifications)

## Stack

| Layer | Choice |
|-------|--------|
| Backend | PHP 8.5, Symfony 8.2 |
| Data | PostgreSQL 17, Doctrine ORM + Migrations |
| UI | Twig, custom editorial design system |
| Ops | systemd bots, Scheduler, CI deploy + smoke |
